## One admin

Laravelify has a single admin account. The first visit to the panel goes to `/setup`, which needs the token from the installer's setup link; after that account exists, there is no registration page.

Logging in is rate limited: five wrong answers (password or authenticator code) for one account from one IP, or twenty from one IP, pause logins for five minutes. The password and the code are both checked before a session starts.

## Two-factor is required

Right after creating the account you set up an authenticator app (Google Authenticator, 1Password, Authy, Bitwarden) and enter the 6-digit code. Until then every page is locked. Later sign-ins at `/login` ask for email, password, and the current code.

The setup page has two choices:

- **New key:** scan the QR code, or copy the key into your app. **Make a different key** gives you another one.
- **Use my own key:** paste a key you already use in another app or password manager, so one entry in your app gives codes for both. A plain key (`JBSW Y3DP …`, spaces do not matter) or an `otpauth://` link both work. It must be at least 16 characters of A–Z and 2–7.

<Warning>
  Keep the setup key from the QR screen somewhere safe. If you lose the authenticator, you need shell access to the server to reset it.
</Warning>

## Your account: Security

Open the menu under your name at the bottom of the sidebar and choose **Security**.

- **Change password:** enter the current password and the new one twice, press **Change password**, then enter your authenticator code to confirm.
- **Show my key:** after your code, shows the key you sign in with, with a copy button, to add it to another app.
- **New key** or **Use my own key:** replace your authenticator key. Scan the new key (or paste your own), enter the code your app shows for it, press **Continue**, and confirm with a code from the key you use today. Codes from the old key stop working right away.

## Secrets stay hidden

Saved tokens and passwords (GitHub token, Telegram bot token, database passwords, webhook secrets, basic auth passwords, server passwords) are encrypted in the database and never sent to the browser. A saved field shows **Saved**.

To see one, click the **eye** icon and enter your authenticator code. Secrets then stay visible for 5 minutes. Five wrong codes block revealing for a minute.

Typing in a saved field replaces the value; leaving it empty keeps the saved one.

## Access prompt for the panel and phpMyAdmin

**Security → Access** puts a browser sign-in box in front of the panel and phpMyAdmin, before any page loads. Scanners and bots never reach the login page or phpMyAdmin at all.

For each of them, choose what the box asks for:

| Choice | How to sign in |
| --- | --- |
| **Authenticator code** | Type your current 6-digit code in the Username box (or the Password box). |
| **Username and password** | A username and password you set on the page. |
| **Password + code** | The username, then the password with your 6-digit code typed right after it (`mypassword123456`). |

- **Allowed IPs** never see the box. One IP or range per line (`203.0.113.7`, `198.51.100.0/24`, IPv6 too). **Add my IP** adds the one you use now. Behind the Cloudflare tunnel the real visitor IP is used.
- After a right answer the browser stays signed in for 1 to 72 hours (you choose).
- Five wrong answers block that IP for 15 minutes.
- Webhooks (`/hooks/...`) and the health check (`/up`) stay open, so deploys and heartbeats keep working.
- Saving asks for your authenticator code.

phpMyAdmin is its own app, so Laravelify adds a short block to its nginx file: nginx asks the panel before each phpMyAdmin page. Turning the box off removes the block again.

<Warning>
  Locked out? On the server run `sudo -u laravelify php /opt/laravelify/artisan laravelify:access-off` (add `panel` or `phpmyadmin` to turn off only one).
</Warning>

## Reset two-factor from the server

```bash
cd /opt/laravelify
sudo -u laravelify php artisan tinker --execute 'App\Models\User::first()->forceFill(["two_factor_secret" => null, "two_factor_confirmed_at" => null])->save();'
```

The next sign-in asks you to set up two-factor again.
