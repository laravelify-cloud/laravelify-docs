## Connect GitHub

<Tabs>
  <Tab title="GitHub App (recommended)">
    **Sources → New GitHub App**. Laravelify creates the app on GitHub for you (manifest flow): you confirm on GitHub, install it on the repositories you want, and come back.

    - Works for private repositories.
    - Uses a short-lived token per deploy; nothing long-lived is stored in the site.
    - Auto deploy is on as soon as the site uses the App: every push to the site's branch deploys it. No webhook to add per repository. The **Deployments** tab shows **Automatic**.
    - If pushes do not arrive, check that the App is installed on that repository (GitHub → **Settings → Applications → your App → Repository access**).
    - Pick the account the App is made in: **Personal account** or one of your organizations (those of your other Apps, and all of yours once a GitHub token is saved in **Settings → GitHub**). An App can only be installed in the account it is made in.
    - The App asks for **Contents: read and write**: deploys only read, and writing lets the panel commit for you (the Sentry SDK) and make new repositories.
    - **Re-register** (on the Sources list) makes a new App on GitHub for a source, with the current permissions, and its websites keep using it. Delete the old App on GitHub afterwards. **Delete** removes a source from the panel; its websites stop deploying on push until they use another source.
  </Tab>
  <Tab title="Personal access token">
    **Settings → GitHub token**. Create a fine-grained token on GitHub with **Contents: read** for the repositories, and paste it. It is stored encrypted.

    Then add a webhook to each repository (below).
  </Tab>
  <Tab title="Public repository">
    Paste the `https://github.com/owner/repo` URL. No token needed. Add a webhook for auto deploy.
  </Tab>
</Tabs>

## Webhooks (token or public repositories)

On the website's **Deployments** tab, copy the **Payload URL** and **Secret**. In GitHub: repository → **Settings → Webhooks → Add webhook**:

| Field | Value |
| --- | --- |
| Payload URL | `https://panel.example.com/hooks/github/{slug}` |
| Content type | `application/json` |
| Secret | the website's secret (click the eye to show it) |
| Events | Just the **push** event |

Laravelify checks the `X-Hub-Signature-256` signature and deploys only when the push is to the site's branch. The **Deployments** tab shows the last delivery and why it did or did not deploy.

## Roll back a deploy

On the **Deployments** tab, the deploy whose code is live is marked **Live**, and every other finished deploy has **Roll back to this**:

1. The code live now is saved first, as a `.tar.gz` in the website's own folder (never served). The rollback's row gets **Replaced code** to download it.
2. The older commit goes live with the usual install, migrations, and restart.

To put the newer changes back, roll back to the newer deploy. The next push to the branch deploys the newest commit again, and database migrations from newer deploys are not undone.

## Auto deploy

Turn **Auto deploy** off on the Deployments tab to keep pushes from deploying (they are still recorded). Use **Deploy** to deploy by hand at any time, and **Stop deploy** to cancel a running one.
