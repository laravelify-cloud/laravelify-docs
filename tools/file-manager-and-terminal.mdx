## File manager

Every website has a **Files** tab, and the sidebar's **File manager** opens all sites (`/var/www`, or the folder set by `LARAVELIFY_FILES_ROOT`).

- Browse with breadcrumbs or type a path; the path is kept in the URL.
- Open text files in an editor with word wrap and full-screen mode; save with <kbd>Ctrl</kbd>+<kbd>S</kbd>.
- Upload files, download files or folders, create, rename, move, and delete (deleting asks you to type the name).
- Saving a Laravel `.env` clears the cached config so the change applies.
- Tick several items for bulk **Copy to**, **Move to**, **Compress to .zip**, and **Delete**.

### Trash

Deleting in the file manager moves files and folders to the **Trash** (the button next to **New folder** shows how many are in it), so nothing is lost by a wrong click.

- **Restore** puts an item back where it was. If that name is taken again, it comes back as `name (restored)`.
- Deleting the same path more than once keeps every version. Open **N versions** to see when each was deleted and by whom, and restore the one you want.
- **Delete for good** (one version) and **Empty trash** ask for the current code from your authenticator app.
- Each website's file manager has its own trash. Items are kept until you delete them for good, so empty the trash now and then to free the disk.

### Compress to .zip without the heavy folders

**Compress to .zip** (on a selection, or in an item's menu) opens a dialog first. It lists the folders inside your selection that a zip usually does not need, already ticked to leave out: `node_modules`, `vendor`, `.git`, `.next`, `.nuxt`, `.output`, `.svelte-kit`, `.angular`, `.astro`, `.cache`, and Laravel's cached views. Build output (`dist`, `build`) and logs are listed but not ticked. Untick anything you want in the zip, choose its name, and press **Compress**. Select several apps to get them all in one zip.

### Big jobs run in the background

Zipping, extracting, downloading a folder as `.zip`, and copying or deleting big folders run in the queue worker, so the page never hangs. A list above the files shows each job with its progress. When it finishes you get a message, the folder refreshes, and a folder download starts by itself. Small copies and deletes still happen at once.

If a job stays on **Waiting**, the queue worker is not running. Check it with `sudo supervisorctl status laravelify-queue`.

## Terminal

Every website has a **Terminal** tab (it starts in the site folder) and the sidebar's **Terminal** works across all sites.

Type `/` for autocomplete of Artisan commands, PM2 commands (`pm2 status`, `pm2 restart`, `pm2 logs`), Supervisor commands, and useful server commands.

Commands run as `www-data` in a sandbox: the rest of the system is read-only, `/tmp` is private, and each command stops after 60 seconds. Use SSH for long or interactive tasks.

## phpMyAdmin

**Sidebar → phpMyAdmin** signs you in with one click, using a one-time link valid for 60 seconds. phpMyAdmin also keeps its normal password sign-in (user `root`, your MySQL root password).

## Links

**Settings → Links** adds your own shortcuts to the sidebar (Cloudflare dashboard, mail, analytics).
