## General

**Settings → General** sets how every date and time in the panel is shown: deployments, logs, monitoring, file times, charts, the live feed, and Telegram messages.

| Setting | Options |
| --- | --- |
| Timezone | All IANA timezones, with today's UTC offset. **Use my timezone** takes it from the browser |
| Date format | `2026-10-12`, `12.10.2026`, `12/10/2026`, `10/12/2026`, `12 Oct 2026`, `Oct 12, 2026`, … |
| Time format | 24-hour or 12-hour, with or without seconds |
| Relative times | "5 minutes ago" for recent events (full date on hover), or the full date everywhere |

Stored times stay in UTC; only the display changes.
