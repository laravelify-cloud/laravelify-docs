## Logs

Website → **Logs** lists every log of the site:

| Group | Logs |
| --- | --- |
| Application | Laravel (`storage/logs/laravel*.log`), or PM2 output for Next.js |
| Supervisor | Each worker's log (queue, scheduler, Reverb, your programs) |
| Other logs | Any other `.log` file in `storage/logs` |
| nginx | The site's access and error logs |

Follow a log live, search it, wrap lines, copy, or clear it.

### Times in your timezone

A log is written in one timezone: the app's, which is UTC unless the site's `.env` sets `APP_TIMEZONE` (nginx's error log uses the server's). The viewer shows the timestamp at the start of each line in **your** timezone (Settings → General, or your browser's), and nginx's access log offset (`+0000`) becomes yours too. The **clock** button above the log switches back to the times as written. A timestamp inside a message is never changed, and search, copy, and download follow what you see.

## Health

Website → **Health** runs checks and explains each result:

- the site answers over HTTP, and how fast;
- the last deploy succeeded;
- every Supervisor worker or the PM2 app is running (with a **Restart** button);
- recent errors in the Laravel log (with a link to the log);
- nginx logs are enabled and `nginx -t` passes.

A worker that keeps crashing also sends a Telegram alert.
