**Sidebar → Server** lists the host services and their status. Open one to edit its config and apply it.

| Service | What applying writes |
| --- | --- |
| MySQL 8.4 LTS | `/etc/mysql/mysql.conf.d/laravelify.cnf`, then restarts MySQL |
| Redis | `/etc/redis/laravelify.conf` (included from `redis.conf`), then restarts Redis. Set a password here |
| phpMyAdmin | Its nginx locations (or its own nginx file), then reloads nginx |
| PHP-FPM 8.0–8.5 | `/etc/php/{version}/fpm/pool.d/www.conf`, then restarts that PHP-FPM |

Sites use the PHP socket `unix:/run/php/php{version}-fpm.sock` of their version.

## phpMyAdmin

New servers serve phpMyAdmin at a path of the panel's address, like `https://panel.example.com/phpmyadmin`, not on a domain of its own. Change the path on **Server → phpMyAdmin**; saving writes the nginx locations again (one-click sign-in included) and puts the old ones back if nginx refuses the new ones. Servers installed with a phpMyAdmin domain move to `/phpmyadmin` when they update to 0.3.0-beta.85 or newer.

Passwords on these pages (the MySQL root password, the Redis password) are shown only after your authenticator code.

## Ports and processes

- **Server → Ports** shows which ports are in use and by which site.
- **Server → Processes** lists every Supervisor program and PM2 app on the server, with restart, start, stop, and logs.

## Nginx page

**Server → Nginx** shows what nginx does on this machine:

- **Test nginx** runs `nginx -t` on every config and shows the result, with nginx's own error message when it fails.
- **Sites and domains** lists every server block with its domains, ports, where it sends traffic (a proxy, PHP, files, or a redirect), the website that owns it, and the file. Files nginx loads that Laravelify did not write are marked **Not managed by Laravelify**.
- **Conflicts**: two server blocks answering for the same domain and port are called out (nginx uses the first one it loads).
- **Ports nginx listens on**, **Error log** (the last lines of `/var/log/nginx/error.log`), and every **config file**, read-only. Change a site's file on its own Nginx tab.
